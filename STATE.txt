### Search strategy (how the agent decides)

| What you need | Tool |
|:---|:---|
| Exact pattern (regex) | `search_files` with `regex: true` |
| Case-insensitive substring | `search_files` with `ignore_case: true` |
| Code by meaning / concept | `semantic_search` |
| Documentation, APIs, current info | `web_search` |

### Key features

- **Semantic search** — sentence-transformers (all-MiniLM-L6-v2), chunks at def/class boundaries, mtime-based cache, fully local
- **Web search** — Exa API with highlights, `type=auto` by default
- **SQLite memory** — ACID, auto-migration from JSON, auto-prune at 200 messages
- **Git integration** — local-only, restore-all for disaster recovery
- **Regex + case-insensitive search**
- **Structured test runner**
- **Confirm-before-planning rule** in system prompt
- **Tool context** — `set_context()` for API keys and globals
