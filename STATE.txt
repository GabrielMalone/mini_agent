# mini_agent — State Log

## Current Architecture

```
mini_agent/
├── mini_agent.py      # Orchestrator: system prompt, _log(), main loop (~210 lines)
├── llm.py             # LLM: call_deepseek() with retry, _parse_stream() with resilience
├── terminal.py        # ANSI colour helpers
├── config.py          # AgentConfig — loads .mini_agent.toml + env vars + CLI flags
├── tools.py           # 7 tools, registry dispatch + summaries
├── safety.py          # ReadSafetyGate + WriteSafetyGate
├── memory.py          # MemoryStore — SQLite-backed (was JSON)
├── test_safety.py     # 25 tests
├── test_memory.py     # 16 tests (was 12, +4 for SQLite)
├── test_tools.py      # 32 tests
├── test_agent_loop.py # 9 tests
├── test_config.py     # 18 tests
├── .mini_agent.toml   # Example project config
└── STATE.txt          # This file
```

### Memory: SQLite backend

- Each message stored as a row: `(id, role, content_json, created_at)`
- `save()` replaces all messages in an ACID transaction — no corruption on crash
- `load()` returns decoded message dicts, strips incomplete tool-call sequences
- `clear()` deletes all rows and vacuums
- Old `.json` memory files are auto-migrated on first run (kept in place)
- DB path is derived by replacing `.json` → `.db` extension

### Tools

| Tool | Args | Gate |
|------|------|:---:|
| `read_file` | `path` | read |
| `write_file` | `path`, `content` | write |
| `edit_file` | `path`, `old_string`, `new_string` | write |
| `list_directory` | `path` | read |
| `run_shell` | `command` | — (cwd locked) |
| `search_files` | `pattern`, `path?` | read |
| `file_info` | `path` | read |

### API retry

3 retries with exponential backoff (1s, 2s, 4s) on 429/5xx/connection errors.

### Streaming resilience

Connection drops mid-stream are caught — partial content and tool calls are returned.

### Adding a tool

1. `@_register("name")` on impl, `@_summarize("name")` on summary
2. JSON schema entry in `TOOLS`
