# mini_agent — Architecture & State

A coding agent powered by DeepSeek V4 Pro. Terminal REPL + Textual TUI.
320 tests, 28 tools, SQLite memory.

## Multi-Agent Support (v2)

Async foreman pattern: parent spawns sub-agents via `spawn_agent(task=...)` or 
batch `spawn_agent(tasks=[...])` which return task_ids immediately. Sub-agents run 
in background threads with their own context, scratchpad, and tool cache. Parent 
polls with `agent_status`, blocks with `collect_agent`, or grabs fastest with 
`collect_any`. Inter-agent messaging via `agent_message` / `agent_read`. Turn 
budget extension via `agent_extend`.

TUI: horizontal per-agent panes in `#subagent-pane` (HorizontalScroll), each 
labeled "Agent N (taskid)" with unique cycling colors (green/yellow/accent/
pulse/red). Sub-agent tokens buffered per task_id and flushed on newlines. 
Borders via CSS `border: solid` on each child RichLog. Divider between static 
pane and subagent area via CSS `border-bottom` on `#static-pane`.

New modules:
- `agent_runtime.py` — SubAgentResult dataclass + AgentRuntime (thread-safe registry)
- `sub_agent.py` — run_sub_agent() — isolated agent loop for background threads
- `tools/agent_ops.py` — spawn_agent, agent_status, collect_agent, collect_any,
  agent_message, agent_read, agent_extend tool implementations
- `retry.py` — _request_with_retry() (extracted from llm.py)
- `stream.py` — _parse_stream() (extracted from llm.py)
- `tools/schema.py` — TOOLS list (extracted from tools/__init__.py)

Config: `sub_agent_max_turns` (default 15, absolute max 25) in AgentConfig.
Limits: max 5 concurrent sub-agents, depth 1 (no recursive spawns).
Sub-agents share the same tool registry, safety layer, and workspace as the parent.

## Key Systems

### Configuration (config.py)
Priority: CLI flags > env vars > `.mini_agent.toml` > hard-coded defaults.
- `DEEPSEEK_API_KEY`, `AGENT_WORKSPACE`, `EXA_API_KEY` env vars
- TOML fields: model, api_key, api_url, stream, quiet, max_messages, max_tokens, verbose, exa_api_key, allow_overwrites, approve_write_ops, no_color
- CLI flags: --workspace, --stream, --quiet, --no-color, --approve, --allow-overwrites, --unrestricted, --help

### Safety (safety.py)
- `ReadSafetyGate`: resolves path, checks it's inside workspace root
- `WriteSafetyGate`: same + overwrite check (blocked unless `allow_overwrites=True`)
- Both return frozen dataclass results — never raw exceptions

### HTTP Retry (retry.py)
- `_request_with_retry()` — exponential backoff on 429/5xx and network errors
- Cancel-aware: accepts `threading.Event`, returns `None` when cancelled
- Uses `requests.Session` when available, falls back to `requests.post`
- 3 retries max, retryable statuses: {429, 500, 502, 503, 504}

### SSE Streaming (stream.py)
- `_parse_stream()` — parses DeepSeek SSE event stream
- Accumulates text content, reasoning blocks, tool call fragments
- Resilient to connection drops — returns partial results instead of crashing
- Name field set once per tool call (API sends atomic names, not fragments)
- Missing `choices` key gracefully skipped

### Memory (memory.py)
SQLite-backed, three-tier management on every save:
1. **Tool result compression** — outputs >6 messages from tail trimmed to first 5 lines
2. **Token-aware pruning** — drops oldest turns until under max_tokens, preserves turn boundaries and tool-call sequences
3. **Summarization** — synthetic summary replacing pruned history
Also: backward/forward orphan detection, transient message stripping, scratchpad table, test output persistence, JSON→DB migration.

### LLM Agent Loop (llm.py)
- `call_deepseek()` — streaming or non-streaming, delegates to retry.py + stream.py
- `run_agent_turn()` — shared by terminal and TUI; handles:
  - Pre-turn injections (scratchpad, plan, git diff, progress checks, circuit breaker)
  - Parallel tool execution via ThreadPoolExecutor
  - **Tool piping**: `_pipe` meta-field on tool calls; dependency graph via Kahn's algorithm; independent tools still parallel; cycle detection falls back to sequential
  - Returns `None` on cancel (propagated from retry.py)
  - Session reuse (one `requests.Session`)
  - Tool cache clearing, circuit breaker, turn summaries
  - Incremental tool execution (fires `on_tool_ready` during stream)
  - max_turns default 100

### Tool Execution (tools/__init__.py)
- `ToolResult(success, content, hint)` — structured, never raw exceptions
- `execute_tool()` — JSON repair → cache check → `_pipe` strip → schema validation → dispatch → approval gate → cache write
- `_repair_json()` — fixes trailing commas, single quotes, unquoted keys (7 repair strategies)
- `_build_error_hint()` — includes valid parameter names so LLM can self-correct
- `_TOOL_CACHE` — per-turn cache for read-only tools; cleared each turn
- `_MODIFIED_FILES` — tracked by write_file/edit_file; used by `verify`
- `_TASK_REGISTRY` — background shell tasks
- `_TOOL_CONTEXT` — context keys: scratchpad path, plan state, turn history, agent runtime
- `_AGENT_RUNTIME` — AgentRuntime singleton for sub-agent management

### Multi-Agent System
- **agent_runtime.py**: `SubAgentResult` (success, turns_used, content, tool_calls) + `AgentRuntime` (register, store_result, get_status, get_result, cancel, cancel_all, active_count). Thread-safe via `threading.Lock`. `store_result()` cleans up tasks and cancel events to prevent memory leak.
- **sub_agent.py**: `run_sub_agent()` — isolated agent loop: init session → prompt → loop: call_deepseek → execute tools → until done or max_turns or cancelled. Handles tool context injection, recursion guard (blocks spawn/agent/collect tools), scratchpad per-agent.
- **tools/agent_ops.py**: Tool implementations for spawn_agent (max 5 concurrent, 15 default / 25 absolute max turns), agent_status (non-blocking poll), collect_agent (blocking collect with 120s timeout).

### Search & Lookup Strategy
| Need | Tool |
|------|------|
| Function/class definition | `find_symbol` (fast, indexed at startup) |
| All callers/references | `find_usages` |
| Exact pattern / regex | `search_files` |
| Code by meaning | `semantic_search` |
| Documentation, APIs | `web_search` |

### Resilience Defenses
| Defense | Where | What |
|---------|-------|------|
| Orphan detection | memory.py | Removes tool messages with no matching assistant, truncates incomplete sequences |
| JSON repair | tools/__init__.py | 7 strategies for common LLM JSON errors |
| Schema validation | tools/__init__.py | Rejects unknown/missing params before execution |
| Self-correction hints | ToolResult.hint | Valid parameter names in error messages |
| Circuit breaker | llm.py | Trips when same call repeats ≥3x in 6-call window |
| Transient messages | memory.py | Injected context stripped from saved history |
| Tool cache | tools/__init__.py | Read-only tools cached within a turn |
| Connection resilience | stream.py | SSE connection drops return partial results, not crashes |
| Cancel propagation | retry.py | Cancel events stop retry loops, return None cleanly |

### Context Injections (all transient — never persisted)
| Injection | When | Role |
|-----------|------|------|
| System prompt | Session start | system |
| Scratchpad | Every turn (from SQLite) | user |
| Active plan | Every turn (if active) | user |
| Recent git log | First turn | user |
| Modified files hint | Turn 2+ | user |
| Progress check nudge | Every 5 tool-using turns | user |
| Circuit breaker warning | When same call repeats | user |
| Scratchpad staleness nudge | Every 3 turns after turn 4 if not updated | user |

### TUI (tui.py)
- Textual framework, three-pane layout (static + subagent + chat) with pane divider
  - **Static pane (top, 35%)**: Final assistant responses, tool calls & results, system commands
  - **Subagent pane (auto-height, max 12)**: Streaming output from sub-agents spawned with visible=True (hidden when idle via display:none)
  - **Chat pane (bottom, 1fr)**: User input, thinking stream, assistant content stream
  - Every message block rendered inside Unicode box-drawing borders (`╭──`, `│`, `╰──`)
  - Final responses promoted from chat pane to static pane on turn completion
- 8 themes: Dawn, Sepia, Ember, Slate, Midnight, Cobalt, Neon, Forest
- Live status bar: git branch/dirty, active tool, turn count, token count, model
- Streaming token display, real-time shell output, dimmed thinking blocks (via theme color), table rendering
- Thinking flush breaks on newlines / 400 chars; `. ` after a digit skipped (numbered lists stay intact)
- Cancel (Ctrl+C), quit (Ctrl+Q), submit (Enter)
- `/clear`, `/help`, `/export`, `/stats`, `/theme <name>` commands
- Approval mode with footer pulse animation
- Worker thread → message queue → drain every 20ms (smooth streaming)
- Sub-agent streaming: `_SubAgentToken` message type; `_TOOL_CONTEXT._tui_queue` wired in `on_mount`; `_spawn_agent._runner` pushes tokens via plain tuples; `_drain` writes to `#subagent-pane`
- Multi-line paste support, markup escaping

### Terminal REPL (mini_agent.py)
- `--workspace`, `--stream`, `--quiet`, `--no-color`, `--allow-overwrites`, `--approve`, `--help`
- `quit`, `clear`, `/export` commands at prompt
- Scratchpad display, tool execution logging with ANSI colour

### Flags
```
--workspace PATH       Set workspace root (default: cwd)
--stream               Stream responses token-by-token
--quiet                Suppress tool execution logs
--no-color             Disable ANSI colours
--approve              Ask confirmation before write/destructive tools
--allow-overwrites     Allow overwriting existing files
--unrestricted         Remove workspace boundary checks (read/write anywhere)
--help, -h             Show help
```
