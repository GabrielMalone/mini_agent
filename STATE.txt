- **Bug**: Tree auto-hid when all nodes done — user only saw flat "linked list"
- **Bug (root cause)**: `_TOOL_CONTEXT.__dict__["_agent_task_id"]` as shared mutable state — 
  race condition where children's spawn messages arrived before parent's node existed

- **Fix**: `parent_node.expand()` so grandchildren are visible
- **Lesson**: Shared global mutable state (`__dict__` on singleton) is unreliable across threads

### Bug fixes (2)
- **eval/scorer.py**: `_check_shell` called `subprocess.run()` without `args` positional —
  `cmd` was parsed via `shlex.split()` but never passed to the call. All shell checks
  crashed with `Popen.__init__() missing 1 required positional argument: 'args'`.
- **tools/__init__.py**: `_fix_unquoted_keys` split non-quoted text character-by-character
  (one list element per char), so the regex `(\w+)(\s*:)` could never match across multiple
  characters. Changed to accumulate consecutive non-quoted chars into segments, matching the
  same segment-level logic used for quoted strings. Fixes `test_unquoted_keys` and
  `test_combined_malformations` in test_resilience.py.

### Scratchpad SQLite table bug fix
- `_write_scratchpad` (file_ops.py), `set_scratchpad` / `get_scratchpad` (memory.py),
  and `_persist_test_output` (shell_ops.py) all opened raw SQLite connections and
  executed INSERT/REPLACE without ensuring the target table existed.
- The scratchpad table is created in `MemoryStore.__init__`, but in test scenarios
  `_TOOL_CONTEXT.scratchpad_path` could point at a fresh DB never initialized that way.
- Fix: Added `CREATE TABLE IF NOT EXISTS` + `INSERT OR IGNORE` (seed row) before every
  DML statement in all four locations. Also changed `set_scratchpad` from silently
  swallowing errors to printing a warning to stderr.

### Sub-agent completion signals (orchestration awareness)
- AgentRuntime: added `_seen_completions` set to track which results have been surfaced
- Added `get_pending_results()` — returns newly-completed results since last call
- Added `get_running_ids()` — returns task_ids of all currently running sub-agents
- `run_agent_turn()` now injects orchestration context at turn start:
  - Shows newly-completed sub-agent results with status
  - Lists still-running sub-agents with reminder to poll
  - Transient message (not persisted to memory)
- Fixed pre-existing deadlock: `store_result` called `clear_inbox` while holding
  `self._lock`; `clear_inbox` also acquires `self._lock` (plain Lock, not re-entrant).
  Inlined the inbox cleanup directly in `store_result`.
