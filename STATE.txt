## Architecture Notes

### Provider System
- Flash/Pro routing: `_compute_complexity()` uses last user message only.
  Cache keyed by `hash(last_user_content)`.
- Fallback chain: primary → fallback providers on 429/5xx. Provider-specific params stripped.
- DeepSeek prompt cache key: `mini_agent-v1-{tool_count}` for KV-cache stickiness.

### Tree-Sitter Multi-Language
- tree-sitter-python for `.py`, tree-sitter-typescript for `.ts`/`.tsx`,
  tree-sitter-javascript for `.js`/`.jsx`. Centralized run_query() in tree_sitter_parser.py.
- `_get_tree_sitter_parser` must return correct language per extension — `.tsx` must use
  `language_tsx()`, not `language_typescript()` (regression test in test_tree_sitter_path.py).
- `_extract_definitions` TSX query uses `(variable_declarator name: ... value: (arrow_function))`
  pattern — tree-sitter-typescript does NOT support `(arrow_function name: ...)`.

### Windows-Specific
- _communicate_windows() in shell_ops.py: read threads + threading.Timer watchdog with
  taskkill /F /T. CREATE_NO_WINDOW set; CREATE_NEW_PROCESS_GROUP removed (caused freeze).
- File reads bypass subprocess on Windows — direct in-process reads.
- Startup warmup: cmd.exe /c rem absorbs antivirus scan delay.
- Bash path quoting: MSYS2 paths must be quoted when building bash wrapper commands.

### Context Injection
- ZONE model: ZONE 1 (immutable prefix), ZONE 2 (append-only log), ZONE 3 (volatile scratch)
- Per-turn injections: handoff, state, tasks, scratchpad, git diff, core memory,
  circuit breaker, compaction, edit risk, pattern rules, progress check, modified files

### Semantic Cache
- tools/semantic_cache.py: Tier 1 exact SHA-256 (~0ms), Tier 2 cosine similarity via
  CodeSearchNet embeddings. Adaptive thresholds. 15-25% cost reduction.

### Git Checkpoint System
- `core/checkpoint.py` — git-based rollback before write_file, edit_file, run_shell.
  One checkpoint per turn via `_checked_this_turn` gating. Falls back to no-op when git unavailable.
- `tools/agent_ops.py` `_restore_file()` — tries `git checkout <path>` first, falls back to session backups.

### Hash-Anchored Editing
- read_file(hash_lines=True): `lineno:hash| content` format. 3-char SHA-256 per line.
- edit_lines: hash-validated line-range edits, batch rejected on any mismatch, applied bottom-up.

### Storm-Breaker
- After 3 consecutive identical failed tool calls, synthesizes explanation message.
  Pattern from Howard Chen's cwcode: "don't crash, talk."

### Agent Ops Split — REMOVED in commit 25d41eb
- The sub-agent system (agents/, tools/agent_spawn.py, agent_collect.py, agent_patterns.py,
  agent_messages.py, reservations.py) was removed.
