# mini_agent — Architecture & State

A coding agent powered by DeepSeek V4 Pro. Terminal REPL + Textual TUI.
466 tests, 28+tools, SQLite memory.

## This Session (2025-05-12)

### New Features
- **MCP Support**: tools/mcp_client.py — McpConnection + McpClientManager, stdio JSON-RPC, tools discovered at startup as mcp/<server>/<tool>, registered into dispatch. Config via [[mcp_server]] TOML blocks. Echo server fixture for testing.
- **Agent Eval Harness**: eval/ module — YAML task format, 8 checker types, run_task/run_suite/load_tasks, temp workspace copies, binary scoring. Zero core changes.
- **Richer Inter-Agent Comms**: tools/agent_messages.py (AgentMessage, 9 types, MSG_TYPE_REGISTRY), tools/agent_patterns.py (fan_out, fan_in, pipeline, barrier, scatter_gather). Old agent_message/agent_read backward compatible.
- **run_shell --timeout param**: configurable timeout (default 60s, max 300s).

### Bug Fixes (17 total)
- llm.py: session close dead code, race on recent_tool_keys (lock), parallel results lost from turn summary, unbounded _turn_history (cap 200)
- config.py + memory.py: max_messages default mismatch (300→500), incremental save compression, Session timeout, save error logging
- agent_ops/patterns: MSG_TYPE_REGISTRY import, agent_inbox None crash, scatter_gather dead loop
- file_ops + eval: edit_file count restriction, read_file line miscount, write_file raw path, eval/metrics NameError
- search_ops: build_ref_index dead code removed

### Critical Fix: collect_agent no longer cancels on timeout
- Before: 120s timeout → cancel agent thread → kill work in progress
- After: reports "still running" — agent keeps working, parent can extend/re-collect
- Prompt updated: check disk before redoing work when error=="Turn budget exhausted"
