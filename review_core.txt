VIOLATION 1.1 — Module too large (Principle 1)
  Lines: 1–666 (entire file)
  Issue:  666 lines mixing 6 distinct concerns:
          - DeepSeek API communication (call_deepseek, ~60 lines)
          - Circuit breaker logic (~30 lines)
          - Agent turn orchestrator (run_agent_turn, ~400 lines)
          - Tool piping / Kahn's algorithm (~120 lines)
          - Turn summary persistence (_save_turn_summary, ~30 lines)
          - Tool result appending (_append_tool_result, ~30 lines)
  Fix:    Extract circuit breaker into a separate circuit.py module.
          Extract tool piping logic into a separate piping.py or executor.py.
          The orchestrator function run_agent_turn itself should be kept
          but delegate to smaller helpers in sibling modules.

VIOLATION 1.2 — Global mutable state (Principle 3)
  Lines: 29–30 (imports), lines ~230, ~250, ~280, ~325–345 (usage)
  Issue:  llm.py reads and mutates global module-level state from tools:
          - _TOOL_CONTEXT._turn_history        (line ~157, _save_turn_summary)
          - _TOOL_CONTEXT._scratchpad_updated   (line ~325)
          - _TOOL_CONTEXT._plan_steps           (line ~335)
          - _TOOL_CONTEXT._plan_done            (line ~336)
          - _MODIFIED_FILES                     (line ~295)
          - clear_tool_cache()                  (line ~253)
          These are imported from tools.__init__ as module globals and
          mutated directly. The _TOOL_CONTEXT object (AgentContext) is
          itself a global singleton.
  Fix:    Pass AgentContext as a parameter into run_agent_turn instead
          of accessing it as a module-level global. This eliminates
          the hidden data flow and makes the dependency explicit.

VIOLATION 1.3 — Magic numbers (Principle 4)
  Line 271: budget = 64000
  Issue:  The token budget constant 64000 is hardcoded inline. It refers
          to the DeepSeek model's context window size. If the model
          changes (e.g., 128K context), this becomes stale silently.
  Fix:    Define CONTEXT_WINDOW_TOKENS = 64000 at module level, or better,
          add it to AgentConfig as a configurable field with this default.

VIOLATION 1.4 — Poor type hints / wrong type (Principle 10)

  Issue:  Uses lowercase `callable` as a type annotation instead of
          `Callable` from typing/collections.abc. `callable` is a built-in

VIOLATION 1.6 — Bare except swallowing (Principle 2, 5)
