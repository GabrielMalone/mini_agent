AUDIT: safety.py, mini_agent.py, tui.py, terminal.py
Design Principles Violations
================================================================================

Principles audited:
 1. Keep modules small and single-purpose
 2. Prefer explicit control flow over hidden magic
 3. No circular imports. No global mutable state unless unavoidable
 4. No magic numbers; use named constants
 5. All tool results must be structured — never raw exceptions
 6. Every file write must go through the safety layer
 7. Every new feature needs at least one test
 8. Prefer small incremental edits over large rewrites
 9. Prefer readable code over clever code
10. Add type hints for public functions. Use clear names; avoid abbreviations
11. Keep prompts, execution logic, tools, and memory in separate modules
12. Do not create new subsystems unless existing architecture cannot handle the need
13. Reuse existing abstractions before introducing new ones
14. Avoid duplicate logic; extract shared behavior carefully
15. If a change touches more than 3 core files, pause and explain the plan first

    Principle: 6 (safety layer enforcement)
